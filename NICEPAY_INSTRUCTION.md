# Инструкция по подключению NicePay для JustKey.ru

## Обзор

Интеграция платежной системы NicePay в интернет-магазин JustKey.ru включает следующие компоненты:

### Созданные файлы:

1. **`config.php`** - обновлен с новыми настройками домена
2. **`includes/nicepay.class.php`** - класс для работы с API NicePay
3. **`nicepay_callback.php`** - обработчик callback-запросов от NicePay
4. **`payment_return.php`** - страница возврата после оплаты

---

## Настройка NicePay

### 1. Регистрация в NicePay

1. Зарегистрируйтесь в личном кабинете NicePay: https://nicepay.ru/
2. Создайте новый магазин (мерчант)
3. Получите следующие данные:
   - **Merchant ID** (ID мерчанта)
   - **Secret Key** (Секретный ключ API)
   - **Callback URL** для получения уведомлений

### 2. Настройка конфигурации

Откройте файл `checkout.php` и замените тестовые значения на ваши реальные данные:

```php
// Строки 96-97 в checkout.php
define('NICEPAY_MERCHANT_ID', 'ВАШ_MERCHANT_ID'); 
define('NICEPAY_SECRET_KEY', 'ВАШ_SECRET_KEY');
```

Или добавьте эти константы в `config.php`:

```php
// Настройки NicePay
define('NICEPAY_MERCHANT_ID', 'ваш_merchant_id');
define('NICEPAY_SECRET_KEY', 'ваш_secret_key');
define('NICEPAY_TEST_MODE', false); // true для тестового режима
```

### 3. Настройка Callback URL в личном кабинете NicePay

В настройках вашего магазина в NicePay укажите:

- **Callback URL (Webhook URL):** `https://justkey.ru/nicepay_callback.php`
- **Return URL (Success URL):** `https://justkey.ru/payment_return.php`
- **Fail URL:** `https://justkey.ru/payment_return.php`

## Как это работает

### Процесс оплаты:

1. **Пользователь оформляет заказ** → `checkout.php`
   - Создается заказ в базе данных со статусом `pending`
   - Инициализируется платеж через NicePay
   - Пользователь перенаправляется на страницу оплаты NicePay

2. **Пользователь оплачивает** → Страница NicePay
   - Пользователь вводит платежные данные на стороне NicePay
   - NicePay обрабатывает платеж

3. **NicePay отправляет callback** → `nicepay_callback.php`
   - NicePay отправляет POST-запрос с результатом оплаты
   - Скрипт проверяет подпись и обновляет статус заказа
   - Отправляется email покупателю с ключами активации

4. **Пользователь возвращается на сайт** → `payment_return.php`
   - Показывается страница с результатом оплаты
   - В зависимости от статуса (успех/неудача/ожидание)

---

## Обработчики статусов платежей

### Успешная оплата (`SUCCESS`, `COMPLETED`, `PAID`)
- Статус заказа меняется на `paid`
- Отправляется email с ключами активации
- Пользователь видит страницу успеха

### Неудачная оплата (`FAILED`, `CANCELLED`, `DECLINED`)
- Статус заказа меняется на `cancelled`
- Пользователь может попробовать оплатить снова

### Ожидание подтверждения (`PENDING`, `PROCESSING`)
- Статус заказа меняется на `processing`
- Пользователь ожидает подтверждения платежа

## Логирование

Все события платежной системы записываются в лог-файл:

```
/logs/nicepay_callback.log
```

Для просмотра логов:
```bash
tail -f logs/nicepay_callback.log
```

## Тестирование

### Тестовый режим

Для тестирования используйте тестовый режим NicePay:

```php
$nicePay = new NicePay(null, null, true); // true = тестовый режим
```

Тестовые карты NicePay (примеры):
- Успешная оплата: `4111 1111 1111 1111`
- Неуспешная оплата: `4000 0000 0000 0002`

### Проверка работы

1. Создайте тестовый заказ
2. Пройдите процесс оплаты
3. Проверьте логи в `/logs/nicepay_callback.log`
4. Проверьте статус заказа в базе данных
5. Проверьте email уведомления

- `pending` - ожидает оплаты
- `processing` - в обработке
- `paid` - оплачен
- `completed` - завершен

## Безопасность

### Проверка подписи

Все callback-запросы от NicePay проверяются с помощью HMAC-SHA256 подписи.

### Рекомендации по безопасности:

1. Никогда не храните секретные ключи в публичном доступе
2. Используйте HTTPS для всех страниц оплаты
3. Регулярно меняйте секретные ключи
4. Мониторьте логи на предмет подозрительной активности
5. Настройте уведомления об ошибках

---

## Дополнительные возможности

### Автоматическая выдача товара

После успешной оплаты ключи активации автоматически отправляются на email покупателя.

### Возврат средств

Используйте метод `refund()` класса NicePay:

```php
$nicePay = new NicePay();
$result = $nicePay->refund($transactionId, $amount, 'Причина возврата');
```

### Проверка статуса платежа

```php
$nicePay = new NicePay();
$status = $nicePay->checkPaymentStatus($transactionId);
```

## Поддержка

При возникновении проблем:

1. Проверьте логи в `/logs/nicepay_callback.log`
2. Убедитесь, что секретный ключ настроен правильно
3. Проверьте, что callback URL доступен из интернета
4. Обратитесь в поддержку NicePay: support@nicepay.ru
